# Resources

Links used to understand and build this kind of tool. Grouped by topic.

## Open source tools

- mtkclient: https://github.com/bkerler/mtkclient (MediaTek, the reference for mtkclient2/)
- edl: https://github.com/bkerler/edl (Qualcomm EDL reference)
- Heimdall: https://github.com/Benjamin-Dobell/Heimdall (open Samsung implementation)
- SP Flash Tool and ResearchDownload: community documentation for Spreadtrum/Unisoc PAC format
- Odin: Samsung's flash tool, community protocol research on XDA

## Android platform docs

- Partition layout: https://source.android.com/docs/core/architecture/partitions
- Fastboot: https://source.android.com/docs/core/architecture/bootloader/fastbootd
- Verified boot: https://source.android.com/docs/security/features/verifiedboot
- Factory Reset Protection: https://source.android.com/docs/security/features/frp
- ADB: https://developer.android.com/tools/adb

## USB and serial
